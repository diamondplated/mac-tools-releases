# Mac Tools downloads

[Download the latest Mac Tools release](https://github.com/diamondplated/mac-tools-releases/releases/latest)

Mac Tools installs, opens, updates, and configures DockPeek and ScreenWren in one native Mac app.

- Mac Tools and DockPeek require macOS 14 or newer.
- ScreenWren requires macOS 26 or newer.
- The apps are included in the Mac Tools download; tool installation works offline.

The current 1.1.0 distribution is locally signed and **not notarized**. It uses the project's persistent local certificate. Other Macs may require manual approval to open it.

Automatic manager updates verify the signed update feed and downloaded archive against the embedded release key. After updating the manager, choose Update in All Apps to update installed tools.

This repository contains public downloads, release metadata, and update feeds. Application source is maintained separately in a private repository. Signing keys and credentials are not published.
